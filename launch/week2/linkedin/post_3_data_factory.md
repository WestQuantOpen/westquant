# LinkedIn Post 3: The Data Factory — 1 Algorithm to Thousands of ML Examples

**Image:** linkedin_3_data_factory.png

One QFT-12 circuit. 960 machine-learning training examples. Five deliverables in parallel.

This is the WestQuant Open pipeline agent.

Here's how it works:

1. Take a quantum algorithm (QFT, Grover, QAOA, etc.)
2. Compile it hundreds of different ways — varying optimization levels, basis gates, layout, routing
3. Each compilation produces a (state, action, next_state, reward) tuple
4. One pipeline run outputs:
   - Benchmark results (JSON + figure)
   - Paper data (LaTeX table + metrics)
   - GitHub demo (README with results)
   - Blog post (markdown, ready to publish)
   - WQT20 training data (JSONL, ready for RL)

All five outputs are generated in parallel. One run takes seconds.

The scale-up is where this gets interesting:

| Input | Output |
|-------|--------|
| 1 circuit | ~500 training examples |
| 13 circuits (3 families) | ~6,500 examples |
| 10 families × 50 instances | ~250,000 examples |
| Full corpus | 100M+ examples |

This is how WQT20 gets trained. Not on synthetic data. Not on a fixed dataset. On real compilation trajectories from real quantum algorithms — generated by an open-source data factory.

The model doesn't execute transformations. It ranks them. The registry determines legal actions. Deterministic math executes. Independent verification certifies.

AI schedules. Mathematics executes. Verification certifies.
