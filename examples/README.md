# WestQuant Open — Examples

Jupyter notebooks demonstrating WestQuant Open capabilities.

| Notebook | What it demonstrates |
|----------|---------------------|
| `01_qft_optimization.ipynb` | Optimize a QFT circuit using representation search |
| `02_generate_ml_dataset.ipynb` | Generate ML training data from a single algorithm |
| `03_qiskit_vs_pennylane.ipynb` | Compare Qiskit and PennyLane compilation on the same circuits |
| `04_representation_search.ipynb` | Search for better transformation sequences |
| `05_hardware_targeting.ipynb` | Compile the same circuit for different hardware topologies |

## Quick start

```bash
pip install westquant[qiskit]
jupyter notebook
```
